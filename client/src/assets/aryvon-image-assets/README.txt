HOW TO ADD:
1. Extract this ZIP.
2. Copy the `products`, `industries`, and `sections` folders into your project's `public/images/` directory.
3. Example usage:
   <img src="/images/products/heavy-duty-hydraulic-hand-pallet-truck.svg"
        alt="Heavy-Duty Hydraulic Hand Pallet Truck" />
4. For the industry image, for example:
   <img src="/images/industries/manufacturing.jpg.svg" alt="Manufacturing material movement" />

IMPORTANT:
- These are original SVG vector illustrations, not real product photographs or manufacturer-specific product images.
- The supplied localhost URLs (localhost:5173) only work on the developer's computer. In deployed website code, use public paths like /images/industries/manufacturing.jpg.svg.
- Add these assets to the source project and redeploy to make them appear on the Vercel website.
- Check the exact file extensions when referencing them: the industry illustrations are `.jpg.svg` to make it clear they are SVG files; you may rename them to `.svg` and update references if desired.
